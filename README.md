# Smart Startup Project Switcher

A **Visual Studio extension** that allows you to cleanly select startup projects from a dropdown menu.

![Preview](https://raw.githubusercontent.com/chkrishna2001/SwitchStartupProject2026/main/smart_startup_preview.png)

No more scrolling up and down the solution explorer tree to change the startup project. Easily identify, group, and manage your run configurations in large enterprise solutions!

## Distinct Features

Compared to traditional project switchers, **Smart Startup Project Switcher** brings:
* **Native 2026 Support**: Built natively for modern Visual Studio architectures.
* **Intelligent Filtering**: Automatically hides Class Libraries and Test projects that cannot be launched, decluttering your dropdown.
* Configure command-line arguments, environment parameters, and multi-project startup clusters simply and cleanly.
